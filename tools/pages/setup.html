Setup

Run your own Cramberry.

About 20 minutes end to end. Steps 1–5 get the bot playing in Discord. Steps 6–7 connect Cubbie. Tick steps as you go; this page remembers.

0 of 7 done
  1. 1

    What you need

    • Python 3.10 or newer (python.org). Check with python --version.
    • A Discord server where you can add bots. Your own test server is perfect.
    • Optional: an AI key (Gemini is free). Without one, Cramberry runs on a built-in caches question bank.
    • Optional: a Cubbie account, to link your own Cubbie. Everything except the Cubbie features works without it.
  2. 2

    Install

    git clone https://github.com/MalaikaKamranKhan/Track3.git
cd Track3
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
copy .env.example .env
    git clone https://github.com/MalaikaKamranKhan/Track3.git
cd Track3
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
cp .env.example .env

    That installs discord.py, FastAPI, Uvicorn, httpx, pypdf and Pillow into a private .venv folder. Your settings live in .env, which is never committed.

  3. 3

    Create the Discord bot

    1. Open the Discord Developer Portal → New Application → name it Cramberry. Upload avatar.png as the app icon.
    2. Bot tab → Reset Token → paste it after DISCORD_TOKEN= in .env. Turn on Message Content Intent and save. Without it, "im cooked" and Explain It answers never fire.
    3. OAuth2 → URL Generator: scopes bot and applications.commands; permissions Send Messages, Read Message History, Embed Links, Attach Files. Open the URL and add the bot to your server.
    4. In Discord turn on Settings → Advanced → Developer Mode, right-click your server → Copy Server ID → paste after DISCORD_GUILD_ID=. Slash commands then appear instantly.

  5. 5

    Start the bot

    .venv\Scripts\python -m cramberry.main
    .venv/bin/python -m cramberry.main

    Wait for Discord bot online as Cramberry#…, then type /battle caches in your server.

    One copy per bot token. If two people run the same token, every command fails with "interaction failed". Stop it with Ctrl+C.

  6. 6

    Give it an HTTPS address (for Cubbie)

    Cubbie calls your bot over the internet, so localhost isn't enough. Keep this running in a second terminal.

    ngrok (the address never changes):

    ngrok http --url=<your-domain>.ngrok-free.dev 8000

    cloudflared (no account; new address every restart):

    cloudflared tunnel --url http://localhost:8000
    1. Put the https:// address in PUBLIC_URL= in .env and restart the bot.
    2. Put the same address in SERVER = "..." at the top of cubbie-skill/squad-link/scripts/squad.py, commit and push.
    3. Check https://<your-address>/health shows {"ok":true,"bots":["discord"]}.
    4. If Cubbie already has the skill, text it update squad-link.
  7. 7

    Connect Cubbie

    install https://github.com/MalaikaKamranKhan/Track3/blob/main/cubbie-skill/squad-link/SKILL.md

    Installs the squad-link skill.

    /link

    In your Discord channel. The key is shown only to you.

    link my study squad

    Cubbie sends a Provide details · Cubbie private page. Paste your key there, never in the chat.

    check my squad and share my course snapshot

    Shares course codes, topics, due dates and submission status. Never grades or files.

    challenge my squad on caches

    Cubbie shows the first question and posts only after you say yes.

    how did the squad battle go?

    Your private recap: rank, what you missed and why.

    update squad-link

    After the bot's server address changes.

Troubleshooting

Slash commands don't show up

Check DISCORD_GUILD_ID is your server and the invite included applications.commands, then restart the bot and reload Discord (Ctrl+R).

Every command says "interaction failed"

Another copy of the bot is running with the same token. Stop it (the bot shows online in the member list while it runs).

"im cooked" or Explain It answers do nothing

Turn on Message Content Intent (step 3), and check nobody ran /quiet (/watch turns it back on).

Battles post without pictures

Add the Attach Files permission to the bot's role, and check IMAGES=on.

Cubbie says the bot "rejected the saved key"

The key is from another bot or data/state.json was reset: type /link in Discord, text link my study squad, and enter the new key on the private page.

Cubbie can't reach the bot ("unreachable")

Check the tunnel and the bot are running, SERVER in squad.py matches your address and is pushed, then text Cubbie update squad-link.
